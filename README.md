🎉 Paper Accepted at MINT 2026!

We are pleased to announce that our paper, “Multimodal Code-Mixed Hindi-English Dataset for Humor Recognition in Conversations,” has been accepted at the 1st Workshop on Multimodal Interaction in Face-to-Face Dialogue (MINT 2026).

Our work introduces a multimodal dataset for humor recognition in code-mixed Hindi-English conversations, using dialogues from the Indian web series Panchayat.

Paper
Title: Multimodal Code-Mixed Hindi-English Dataset for Humor Recognition in Conversations

Authors: Abhishek Singh Bisht, Rakesh Kumar, and Amrita Chaturvedi
